# Mobile App Guide

Donezy works on iOS and Android, letting you manage tasks and track time on the go.

## Getting Started with Mobile

### Installation

**iOS:**
1. Open App Store
2. Search for "Donezy"
3. Tap "Get"
4. Use Face ID or password to install

**Android:**
1. Open Google Play Store
2. Search for "Donezy"
3. Tap "Install"
4. Sign in with your Google account

### Logging In

1. Open the Donezy app
2. Enter your email
3. Enter your password
4. Tap "Sign In"
5. Confirm your identity if prompted

## Mobile Navigation

The mobile app has a simplified interface optimized for touch:

### Bottom Navigation Bar
- **Home** - Dashboard with quick access to tasks
- **Tasks** - Your task list
- **Time** - Time tracking
- **Messages** - Team communication
- **More** - Additional features (Projects, Notes, Settings)

### Home Screen
Shows your daily overview:
- Active timer
- Today's tasks
- Due soon tasks
- Recent activity

## Managing Tasks on Mobile

### View Your Tasks
1. Tap **Tasks**
2. Scroll to browse your task list
3. Filter by status, project, or assignee
4. Tap a task to open details

### Create a Task
1. Tap **+** button (bottom right)
2. Enter task title
3. Choose project
4. Set due date (optional)
5. Tap "Create"

### Edit a Task
1. Open the task
2. Tap the pencil icon
3. Make changes
4. Tap "Save"

### Complete a Task
1. Find the task in your list
2. Swipe left to reveal options
3. Tap the checkmark to complete
4. Or tap the task and change status

### Add Comments
1. Open a task
2. Scroll to "Comments" section
3. Type your comment
4. Tap "Post"

## Time Tracking on Mobile

### Start a Timer
1. Tap **Time** tab
2. Select a project from the dropdown
3. Select a task (optional)
4. Tap "Start Timer"

The timer will run in the background and show in the status bar.

### Stop & Save Timer
1. Tap **Time** tab
2. Tap the running timer
3. Review time tracked
4. Add notes if needed
5. Tap "Save"

### Manual Time Entry
1. Tap **Time** tab
2. Tap "Add Manual Entry"
3. Select project and task
4. Enter hours/minutes
5. Set date and time
6. Tap "Save"

### View Time History
1. Tap **Time** tab
2. Scroll down to see recent entries
3. Tap "View All" for complete history
4. Filter by project or date

## Projects on Mobile

### Browse Projects
1. Tap **More** → **Projects**
2. Scroll to view all projects
3. Tap a project to see tasks
4. Tap "+" to add new task to project

### Create a Project
1. Tap **More** → **Projects**
2. Tap "+" button
3. Enter project name
4. Add description (optional)
5. Tap "Create"

### Project Quick Actions
1. Open a project
2. Tap the three dots menu
3. Options:
   - Edit project
   - Add members
   - View timeline
   - Archive project

## Messages & Communication

### Check Messages
1. Tap **Messages**
2. See your message list
3. Tap a conversation to open
4. Scroll to read message history

### Send a Message
1. Tap **Messages**
2. Tap "+" button
3. Select recipient(s)
4. Type your message

### Comments on Tasks

2. Scroll to "Comments" section
3. Type a comment

3. Enter title

5. Tap "Save"

### View Notes
1. Tap **More** → **Notes**
2. Browse your notes
3. Tap a note to open
4. Tap pencil to edit

### Share a Note

2. Tap share icon

## Dashboards on Mobile

### View Dashboard
1. Tap **Home**
2. Scroll to see dashboard widgets
3. Tap a widget for more details

### Quick Stats

## Notifications

### Enable Notifications
1. Tap **More** → **Settings**
2. Tap "Notifications"
3. Toggle notifications on
4. Choose notification types
5. Save

### Notification Types
- Task assignments
- Due date reminders
- Mentions
- Message replies
- Time tracking reminders

## Offline Mode

Donezy works partially offline:
- View cached tasks
- View cached messages
- Cannot create new items
- Cannot edit items
- Changes sync when online

### Sync Changes
1. Make changes while offline
2. Go back online
3. Changes automatically sync
4. You'll see a sync indicator

### Account Settings
1. Tap **More**

4. Options:
   - Change password
   - Update email
   - Enable 2FA
   - Logout

### App Preferences

## Syncing Across Devices

Your Donezy account syncs across all devices:
- Make changes on phone, see on desktop
- Time tracking syncs instantly
- Messages appear everywhere
- Notes are always up-to-date

## Performance Tips

- **Clear cache** regularly if the app runs slow
- **Close background apps** to save battery
- **Enable WiFi** for faster syncing
- **Enable dark mode** to save battery
- **Update regularly** for bug fixes and features

## Troubleshooting

**App won't open?**
- Force close and reopen
- Clear app cache in Settings
- Reinstall if needed

**Timer not tracking?**
- Check if app has background permissions
- Enable background app refresh in phone settings

**Changes not syncing?**
- Check internet connection
- Pull down to manually refresh
- Check sync status in Settings

**Notifications not working?**
- Enable notifications in app settings
- Enable notifications in phone settings
- Check notification settings per event type

## Data & Privacy

- Your data is encrypted in transit
- Offline content is stored securely on device
- Clear app data to remove offline content
- Data syncs only to Donezy servers

## Mobile Limitations

Some features work best on desktop:
- Bulk editing tasks
- Advanced reports
- Admin settings
- Custom dashboards
- API access
