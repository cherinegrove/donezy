## Customizing Shortcuts

1. Go to **Settings** → **Keyboard Shortcuts**
2. Search for an action
3. Click and enter your preferred shortcut
4. Save changes

## Tips for Using Shortcuts

- **Most common**: Use `Ctrl+K` (Cmd+K) to open the command palette - you can search for any action
- **Arrows + Letter combos**: Use `J/K` instead of arrows for faster navigation
- **Use what you remember**: You don't need to memorize all shortcuts, just use the ones that speed up your workflow
- **Custom shortcuts**: Create custom shortcuts for actions you do most frequently
- **Two-hand shortcuts**: Combine modifiers for rarely-used features

## Accessibility

If keyboard shortcuts don't work for you:
- All features are available through the UI
- Enable accessibility mode in Settings
- Use voice commands with supported browsers
- Contact Support for custom accessibility options
