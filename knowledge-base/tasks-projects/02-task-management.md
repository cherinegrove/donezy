# Task Management

Master working with tasks efficiently in Donezy.

## Task Views

### List View
- Default view with task rows
- See all task details at a glance
- Filter, sort, and search
- Best for: Overall task management

### Kanban View
- Organize by status (columns)
- Drag tasks between statuses
- See visual progress
- Best for: Workflow tracking

### Gantt View
- Timeline view of tasks
- See dependencies visually
- Adjust dates by dragging
- Best for: Project scheduling

### Calendar View
- Tasks shown on calendar
- Due dates highlighted
- See what's due when
- Best for: Planning

### Timeline View
- Sequential task timeline
- Track dependencies
- See project progress
- Best for: Complex projects

## Finding Tasks

### Search

1. Use the search bar (Ctrl+F)
2. Type task title or keywords
3. Results appear instantly
4. Click to open task

### Filters

Click **Filter** to narrow down tasks:

**By Status**
- Backlog
- Todo
- In Progress
- In Review
- Done
- On Hold
- Cancelled

**By Project**
- Select specific projects
- Multi-select available

**By Person**
- Assigned to me
- Assigned to specific person
- Unassigned

**By Priority**
- Urgent
- High
- Medium
- Low

**By Due Date**
- Overdue
- Due today
- Due this week
- Due next week
- Due later

**By Labels**
- Select one or more labels
- Show only tagged tasks

**By Time Estimate**
- Tasks under 1 hour
- 1-4 hours
- 4-8 hours
- 8+ hours

### Saved Filters

Save filter combinations:

1. Set up filters
2. Click **Save Filter**
3. Name the filter
4. Use anytime

**Common Filters:**
- "My Open Tasks" - Assigned to me, status not Done
- "Due Tomorrow" - Due date tomorrow
- "High Priority" - Priority = High
- "Ready to Review" - Status = In Review

## Sorting

Sort by:
- **Due Date**: Earliest due first
- **Priority**: Urgent → Low
- **Created**: Newest first
- **Updated**: Recently changed first
- **Assignee**: Alphabetically
- **Estimate**: Smallest to largest
- **Time Tracked**: Most time first

Click column header to reverse sort direction.

## Updating Task Status

### Change Status

1. Click the task
2. Click the status dropdown
3. Choose new status
4. Saves automatically

**Typical Status Flow:**
- Backlog → Todo (when starting)
- Todo → In Progress (when working)
- In Progress → In Review (when done)
- In Review → Done (when approved)

Or skip steps for simpler workflows.

### Quick Status Change

In list view:
- Click status directly
- Select new status
- No need to open task

Or drag task in Kanban view to new status.

## Assigning & Reassigning

### Assign to Someone

1. Open task
2. Click **Assignee**
3. Select person or team
4. Saves automatically

Assignee gets notification they're assigned (unless they disabled it).

### Assign to Multiple People

Use **Collaborators** to add people without making them primary assignee:

1. Open task
2. Click **Collaborators**
3. Add multiple people
4. They get notifications and can help

### Self-Assign

Click **Assign to Me** to quickly assign yourself.

## Editing Task Details

### Change Due Date

1. Open task
2. Click due date
3. Choose date from calendar
4. Or type date (e.g., "Friday", "Next week")

### Change Priority

1. Open task
2. Click priority
3. Select Urgent / High / Medium / Low
4. Saves immediately

### Edit Description

1. Open task
2. Click description
3. Edit with rich text editor
4. Click Save

### Add Labels

1. Open task
2. Click **Labels**
3. Type to search existing labels
4. Click to add or create new
5. Remove by clicking X

### Estimate Hours

1. Open task
2. Click **Estimate**
3. Enter hours
4. Saves automatically

Compare estimate to actual time tracked.

## Comments & Collaboration

### Add a Comment

1. Open task
2. Scroll to comments
3. Type in comment box
4. Click **Post**

### Mention Someone

In comments:
1. Type `@` mention symbol
2. Select person
3. They get notified

### React to Comments

Click emoji icon on comments to react with:
- 👍 / 👎 Like/Dislike
- 😂 / 😮 / ❤️ Other reactions
- Custom emoji

### Reply to Comment

Click **Reply** on a comment to:
- Create a comment thread
- Keep discussion organized
- Notify original commenter

## Linking Related Tasks

### Add Links

1. Open task
2. Click **Links**
3. Choose link type:
   - **Blocks**: This task blocks another
   - **Depends on**: Needs another task first
   - **Related**: Just connected
4. Search and select task

### View Linked Tasks

Linked tasks show in task details with relationship type.

## Subtask Management

### Add Subtasks

1. Open task
2. Click **Subtasks**
3. Click **Add Subtask**
4. Enter title
5. Create

### Complete Subtask

Click checkbox next to subtask to mark complete.

### Subtask Progress

Progress bar shows subtask completion percentage.

## Time Tracking for Tasks

### Track Time

1. Open task
2. Start timer from there
3. Or add manual time entry
4. Time accumulates on task

### View Time Summary

In task details:
- Hours tracked
- By whom
- On what dates
- Billable vs. non-billable

### Compare to Estimate

See how actual time compares to estimate:
- Under budget (spent less)
- On budget
- Over budget

## Task Notes

### Add Notes to Task

1. Open task
2. Scroll to **Notes**
3. Type notes
4. Saves automatically

Use notes for:
- Progress updates
- Blockers
- Questions
- Reference links

## Attachments

### Attach Files

1. Open task
2. Click **Attachments**
3. Drag file or click to upload
4. File attached to task

**Supported files:**
- Images (PNG, JPG, GIF, SVG)
- Documents (PDF, Word, Excel)
- Archives (ZIP, RAR)
- Code files

### View Attachments

Click attachment to:
- Download
- Preview (if supported)
- Delete

## Custom Fields

### Set Custom Fields

If configured for your team:

1. Open task
2. Scroll to **Custom Fields**
3. Fill in fields specific to your needs
4. Examples: Client, Budget, Hours, Priority Code

## Activity History

### View Task History

1. Open task
2. Click **Activity** tab
3. See all changes:
   - Who changed what
   - When they changed it
   - Previous and new values

Useful for:
- Tracking decisions
- Finding when status changed
- Understanding task evolution

## Bulk Actions

### Edit Multiple Tasks

Select several tasks to:
- Change status
- Change priority
- Add labels
- Reassign
- Delete
- Archive

1. Select tasks (checkbox)
2. Click **Bulk Actions**
3. Choose action
4. Confirm

## Archiving vs. Deleting

### Archive Task

1. Open task
2. Click menu → **Archive**
3. Task hidden from lists
4. Can be recovered

Use for: Completed tasks you might reference later.

### Delete Task

1. Open task
2. Click menu → **Delete**
3. Confirm deletion
4. Permanently removed

Use for: Duplicate or erroneous tasks.

## Task Notifications

Get notified when:
- Assigned a task
- Due date approaches
- Status changes
- Someone comments
- Someone mentions you

Control in **Settings** → **Notification Preferences**

✅ Keep updated

## Troubleshooting

**Can't find a task?**
- Try searching by title
- Check filters
- Look in project view

**Can't edit a task?**
- Verify you have edit permissions
- Check if task is locked
- Try refreshing

**Notification not sent?**
- Check notification preferences
- Verify you're not muting task
- Confirm other person's settings
