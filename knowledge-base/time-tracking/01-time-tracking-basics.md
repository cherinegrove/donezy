# Time Tracking Basics

Time tracking in Donezy helps you understand where your time goes and provides data for reporting, billing, and productivity insights.

## Why Time Tracking Matters

Time tracking helps with:
- **Invoicing**: Track billable hours for clients
- **Project costing**: Understand project profitability
- **Productivity**: See what takes longest
- **Planning**: Make better estimates
- **Accountability**: Track team utilization
- **Reporting**: Generate timesheets and reports

## Starting a Timer

### Quick Timer Start

1. Click the **Time Tracking** card on your dashboard
2. Select a project from dropdown
3. Optionally select a task
4. Click **Start Timer**

Timer runs in background and shows elapsed time.

### Start from Task

1. Open a task
2. Click **Start Timer**
3. Timer starts for that task automatically
4. Background continues tracking

### Using Chrome Extension

1. Click Donezy extension icon
2. Select project
3. Select task (optional)
4. Click "Start Timer"
5. Works even if browser tab closed

See [Chrome Extension Guide](../getting-started/05-chrome-extension.md) for details.

### Using Mobile App

1. Open Donezy mobile app
2. Go to **Time** tab
3. Select project and task
4. Click "Start Timer"
5. Continues tracking in background

## Stopping & Saving Time

### Stop Your Timer

1. Go to **Time Tracking** page
2. Click the running timer card
3. See elapsed time
4. Click **Stop**

### Save Time Entry

After stopping:

1. Review the time tracked
2. Add **Notes** about what you worked on
3. Verify **Start Time** and **End Time**
4. Click **Save**

Time is now recorded and appears in reports.

### Edit Time Before Saving

1. Stop the timer
2. Click on start or end time
3. Adjust time as needed
4. Click **Save**

Use this if timer started/stopped at wrong time.

## Manual Time Entry

For work completed earlier:

### Add Manual Entry

1. Click **Time Tracking**
2. Click **Add Manual Entry**
3. Select **Project**
4. Select **Task** (optional)
5. Set **Date** (when you worked)
6. Set **Start Time**
7. Enter **Hours or Minutes**
8. Add **Notes**
9. Click **Save**

### Bulk Add Time

Add multiple time entries at once:

1. Click **Time Tracking**
2. Click **Bulk Add**
3. Upload CSV with entries:
   - Project, Task, Date, Hours, Notes
4. Review data
5. Click **Import**

## Time Entry Details

### What to Track

Track time for:
- **Billable work**: Client project tasks
- **Internal work**: Company projects
- **Support**: Help colleagues
- **Training**: Learning new skills
- **Admin**: Planning, meetings, etc.

### Adding Notes

When saving time, add notes describing:
- What you worked on
- Progress made
- Blockers encountered
- Resources used
- Why it took that long

Examples:
- ✅ "Implemented login form with validation"
- ✅ "Debugging 404 error - found in routing config"
- ✅ "Code review - 5 pull requests"
- ❌ "Working"
- ❌ "Stuff"

### Billable vs Non-Billable

Mark time as billable or not:

1. Open time entry
2. Toggle **Billable** switch
3. Saves automatically

Billable time used for:
- Client invoicing
- Project profitability
- Revenue tracking

## Viewing Time

### Daily Summary

On dashboard:
- Total hours today
- By project breakdown
- Recent entries
- Time since start of week/month

### Time Log

View all your time entries:

1. Go **Time Tracking** → **Time Log**
2. See all time entries
3. Filter by project, date, or task
4. Click to edit entry

### By Project

See time spent on each project:

1. Open a **Project**
2. Go to **Project Stats**
3. See hours by task
4. See team member hours
5. See billable hours

### By Task

See time spent on task:

1. Open a **Task**
2. Scroll to **Time Tracked**
3. See all entries
4. See by team member
5. Compare to estimate

## Time Formatting

### Entering Time

Enter time as:
- **Decimal**: 2.5 (2 hours 30 minutes)
- **Minutes**: 150 (minutes)
- **Colon**: 2:30 (hours:minutes)
- **Words**: "1 hour 30 minutes"

Donezy converts to standard format.

## Editing Time Entries

### Edit an Entry

1. Go **Time Tracking** → **Time Log**
2. Find the entry
3. Click to open
4. Edit:
   - Project or task
   - Date, start time, duration
   - Notes
   - Billable status
5. Click **Save**

### Delete Entry

1. Open time entry
2. Click menu → **Delete**
3. Confirm deletion

Deleted entries don't appear in reports.

## Timer Behavior

### Multiple Timers

**Only one timer can run at a time.**

Starting new timer automatically:
- Stops previous timer
- Shows save dialog
- Prevents accidental overlap

### Background Tracking

Timer continues in background when:
- Browser tab changes
- Browser window closed (web version)
- App minimized (mobile)
- Working on other things

**Note**: Phone timer stops if app completely closed.

### Idle Detection

Some setups detect idle time:
- Pauses timer automatically
- Alerts you to activity
- Prevents tracking inactive time

Check your notification preferences.

## Time Targets & Goals

### Set Daily Target

1. Go **Settings** → **Preferences**
2. Set **Daily Target Hours**
3. Dashboard shows progress toward target

Helps track if you're hitting goals.

### Weekly Goals

1. Go **Dashboards** → **My Time**
2. See weekly target (usually 40 hours)
3. See progress
4. Adjust in settings

## Time Reminders

### Get Reminded to Log Time

Enable reminders in **Settings** → **Notifications**:
- End of day reminder
- Weekly timesheet reminder
- Untracked time warning

### Timer Reminders

Get notified:
- When timer has been running long
- To save time before leaving
- To add notes before forgetting

## Reporting Time

### Generate Reports

1. Go **Dashboards** → **Reports**
2. Choose report type:
   - Personal timesheet
   - Team summary
   - By project
   - By client
   - Billable hours
3. Set date range
4. Download or share

### Export Data

Export time entries as CSV:

1. Open time log
2. Click **Export**
3. Choose date range
4. Download file
5. Open in Excel or Google Sheets

## Privacy & Visibility

### Who Sees Your Time?

- **Managers**: See their team's time
- **Project managers**: See project time
- **Yourself**: See your own time
- **Admins**: See all time
- **Clients**: See time on their projects (with permission)

### Hiding Time

You can mark entries private:
1. Open entry
2. Toggle **Private**
3. Only you and admins can see

## Best Practices

### Log Daily
- Log time same day you work
- Don't wait until end of week
- Details are fresher in your mind

### Be Specific
- Use clear project and task names
- Add meaningful notes
- Helps with future estimation

### Regular Estimates
- Compare actual to estimated time
- Refine estimation accuracy
- Improves future planning

### Account for All Time
- Track all work time
- Including meetings, planning, breaks
- Helps with realistic scheduling

### Weekly Review
- Review hours on Friday
- Ensure everything logged
- Plan next week realistically

## Keyboard Shortcuts

- **Ctrl+Space**: Start/stop timer (Cmd+Space on Mac)
- **Shift+T**: Open time tracking
- **T**: Start timer for selected task

See [Keyboard Shortcuts](../getting-started/03-keyboard-shortcuts.md) for more.

## Troubleshooting

**Timer not running?**
- Check browser hasn't auto-closed
- Verify internet connection
- Reload page and try again

**Time not saving?**
- Check internet connection
- Try saving again
- Contact support if persists

**Wrong time shown?**
- Check device time is correct
- Can edit before/after saving
- Contact support for adjustments

**Not seeing time on report?**
- Verify time marked billable (if needed)
- Check date range
- Verify correct project/task
